# Página web de videojuegos

## Descripción

Este proyecto consiste en una página web estática dedicada a los videojuegos. La página contiene información, imágenes, contenido multimedia y funcionalidades desarrolladas con HTML, CSS y JavaScript.

Para el diseño de la interfaz se utilizó Bootstrap, mientras que JavaScript permite realizar diferentes acciones sobre el contenido de la página y almacenar registros mediante LocalStorage.

## Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript
* Bootstrap
* Git
* GitHub
* GitHub Pages
* LocalStorage

## Ejecución local

Para ejecutar el proyecto localmente se debe clonar el repositorio:

```bash
git clone https://github.com/TU_USUARIO/Paginaweb.git
```

Entrar a la carpeta:

```bash
cd Paginaweb
```

Después se puede iniciar un servidor local utilizando Python:

```bash
python3 -m http.server 8000
```

Finalmente, abrir en el navegador:

```text
http://localhost:8000
```

## Funcionalidades

La página cuenta con:

* Barra de navegación.
* Información sobre videojuegos.
* Imágenes de Cyberpunk 2077, Elden Ring, Red Dead Redemption 2 y The Witcher 3.
* Contenido multimedia.
* Diseño utilizando Bootstrap.
* Botones con funciones JavaScript.
* Registro de videojuegos.
* Manipulación del DOM.
* Almacenamiento de registros mediante LocalStorage.

## Registros
La aplicación permite agregar videojuegos mediante un formulario. Los registros se almacenan en LocalStorage del navegador para conservar la información después de recargar la página.

## Control de versiones
El proyecto utiliza Git para registrar los avances realizados durante el desarrollo. Se realizaron diferentes commits para identificar las modificaciones del HTML, imágenes, estilos CSS y funcionalidades de JavaScript.
